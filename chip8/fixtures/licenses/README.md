# Fixture licences

The generated smoke ROM contains no third-party game code. Its provenance uses
`LicenseRef-Program-Diffusion-Generated` to identify repository-authored test
material without asserting an unrelated upstream licence.

The paper-only ROMs have separate upstream terms and are not covered by the
repository's BSD-3-Clause license. `paper/cohort.toml` records each ROM's
license and pinned evidence: IBM Logo Test is GPL-3.0; Horse World Online and
Octojam 2 Title are CC0-1.0. The exact source revisions and URLs are also
listed in `../source/public/README.md`.
