# TIC-80 E3 sources

This directory contains Lua source for the eight pakettic entries in
`../paper/e3/cohort.json`:

- Eight Lua programs from `vsariola/pakettic` at revision
  `480f033bdf78ec628f6be8bc3ac58d8616451361`. Their three upstream MIT
  notices are preserved in `../../licenses/`.
- The other five artifact-bearing site carts use source paths recorded in the
  cohort manifest. The three that also appear in CE1 reuse its existing
  `paper/ce1/` files. Gravity and Snow each have one original `.tic` file under
  `paper/e3/`, referenced as both source and artifact.

The other 17 cohort entries are metadata-only. Their URLs and digests are in
the cohort manifest; no cart bytes for those entries are stored here.
