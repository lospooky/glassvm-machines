# Fixture licences

The Gecko cartridge and official TIC-80 Lua demo are MIT licensed. The Gecko
licence is copied as `gecko-MIT.txt`; the TIC-80 project licence is retained in
the reference corpus.

The E3 cohort preserves the three original MIT notices from the pinned
pakettic author folders, plus the applicable site-cart license text for the
five included public carts. `paper/e3/cohort.json` associates each artifact
with its license evidence. The remaining 17 E3 entries are metadata-only and
have no cart bytes in this repository.
