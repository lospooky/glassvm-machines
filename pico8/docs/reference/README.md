# PICO-8 reference provenance

This directory records link-only primary references and the open-source
cartridge-decoder implementation used to establish the bundle's format and
machine boundary. No proprietary PICO-8 executable, firmware, cartridge, or
manual is vendored here.

- Lexaloffle PICO-8 manual: <https://www.lexaloffle.com/dl/docs/pico-8_manual.html>
- Lexaloffle PICO-8 product page: <https://www.lexaloffle.com/pico-8.php>
- `pico8_decompress` (MIT): <https://github.com/shanecelis/pico8_decompress>
- `pico8-to-lua` crate metadata: <https://crates.io/crates/pico8-to-lua>

`sources.toml` captures these references in machine-readable form. Captured
reference material belongs only in `corpus/`; `SHA256SUMS` covers that corpus
exactly. At present the corpus contains only its explanatory README.
