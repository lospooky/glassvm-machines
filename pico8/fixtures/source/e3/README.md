# PICO-8 E3 cohort sources and license terms

The E3-only numbered carts are reconstructed from the Fraser PICO-8 Games
Dataset representation. Filenames preserve original candidate indices
(04–22 and 24–30); the first three E3 members reuse the canonical CE1 files in
`../../paper/ce1/`. Author, BBS URL, per-cart CC BY-NC-SA marker, dataset
revision digest, and artifact digest are listed in `../../paper/e3/cohort.json`.
These reconstructions are not asserted to be byte-identical to the original
BBS uploads. Each retained file is also its canonical E3 artifact, so source
and output copies are not duplicated.

The 30th selected artifact is Fire Intro. Its pinned upstream MIT source is
`../public/fireintro.p8`; `build_paper_workload.py` makes the documented
presentation-only title normalization. The source license is retained at
`../public/fire-intro-effect-MIT.txt`.

The cohort combines 29 Fraser-derived carts and one separately sourced MIT
adaptation. The dataset reports per-cart CC BY-NC-SA 4.0 markers for the 29
reconstructions. The cohort records the corresponding attribution,
noncommercial, ShareAlike, and modification terms. Those metadata reflect the
pinned dataset's license declarations, not independent author confirmations.
These third-party assets are not covered by the repository's BSD-3-Clause
license.
