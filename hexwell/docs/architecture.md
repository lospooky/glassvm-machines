# Hexwell architecture

The native core treats a ROM as one immutable 256-byte row-major catalyst
plate. It owns concentrations, heat, sparks, tide, synchronous arbitration,
matter conservation, frame cooling, rendering, native evidence, and native
continuation without importing GlassVM.

The verifier depends only on core decoding and geometry. The plugin translates
native reports and sweep effects into GlassVM capabilities, diagnostics,
events, observables, bodies, replay, and session-bound snapshots.
